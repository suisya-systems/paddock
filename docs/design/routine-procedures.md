# Routine procedures: audit against principle 9

Status: audit, 2026-11-11 (Issue #173). Nothing here is built. The rule is [architecture §2, principle 9](architecture.md#2-design-principles): a fixed procedure the discipline makes an agent repeat goes through a tool, not a sentence.

**Read:** `templates/` (secretary, worker, worker rules; the settings file has no procedure text), the eight `skills/*/SKILL.md`, the README, every file in `docs/design/` and `docs/decisions/`, with the decisions of 2026-11-10 and 2026-11-11 and their consequences in [open questions](open-questions.md) and the [predecessor inventory](predecessor-inventory.md).

**Cases:** **A** a tool exists and the text points to it; **B** a tool exists, but the text also has the agent do the steps by hand or does not name the tool; **C** no tool.

**Order:** by how often the procedure runs, estimated from the rules themselves (for example the 60 s wait timeout); none of it is measured.

**Left out:** judgment (answering a question, a PR's title and body, what a handover says, reading a screen after exit 10), one-off setup (trusting the workers folder, Q13; the token file, Q20; the Windows note, Q7), one migration (approvals without `answer_in`, secretary.md line 78), conversation (telling the person a wait started) and host probes (one run each): none repeats in a fixed form. The `cp -i` alias of INS-14 also stays out: no small tool was found for it.
